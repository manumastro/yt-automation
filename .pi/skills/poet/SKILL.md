# 🎭 Protocollo POET — Polish Narrativo Finale

Trasforma uno script già scritto in una versione più forte, memorabile e fluida senza cambiare format e struttura del canale.

## Quando usare

- Dopo SCRIPT STEALING, prima della produzione
- Quando lo script è corretto ma "piatto"
- Quando serve aumentare retention, ritmo e payoff emotivo

## Input richiesti

1. Script da rifinire:
   - `output/<canale>/production/<YYYY-MM-DD>_<slug>/script.md`
2. File formula canale (consigliati):
   - `output/<canale>/clerk/script_blueprint.md`
   - `output/<canale>/clerk/hook_playbook.md`
   - `output/<canale>/clerk/sop_ai.md`
3. Lingua finale script (default: stessa lingua dello script)

## Procedura

### FASE 1 — Diagnosi rapida

Valuta script su 5 aree:
1. Hook impact (primi 3 secondi)
2. Ritmo frasi (variazione lunghezza, pause, punch)
3. Tensione narrativa (open loops, escalation)
4. Precisione lessicale (verbi forti, immagini concrete)
5. Payoff finale (chiusura memorabile)

### FASE 2 — Rewrite poetico controllato

Riscrivi mantenendo:
- stessi fatti principali
- stessa struttura a entry/listicle
- stesso tono core del canale

Migliora:
- transizioni interne
- sonorità/musicalità del testo
- chiarezza e punchline finali per entry

### FASE 3 — Guardrail

- Non alterare claim fattuali
- Non introdurre stile fuori brand
- Non aggiungere filler o CTA non previsti
- Non cambiare il formato del blueprint

### FASE 4 — Output finali

Nella stessa cartella production crea/aggiorna:
1. `script_final.md` — versione poet-refined
2. `poet_notes.md` — cosa è stato migliorato (bullet sintetici)
3. `qa_checklist.md` — aggiornare con check di ritmo/payoff finali

## Output attesi

- `output/<canale>/production/<YYYY-MM-DD>_<slug>/script_final.md`
- `output/<canale>/production/<YYYY-MM-DD>_<slug>/poet_notes.md`
- `output/<canale>/production/<YYYY-MM-DD>_<slug>/qa_checklist.md` (aggiornato)

## Regole operative

- POET è refinement, non riscrittura totale fuori formula
- Mantieni coerenza totale con CLERK blueprint
- Se mancano script o file base, fermati e chiedi integrazione
- Salva sempre output su file
