## Video 1: The City That Inspired Silent Hill

**Pillar:** Ghost Towns  
**Idea:** Centralia, Pennsylvania — la città che ha ispirato Silent Hill  
**Hook:**
> "Centralia. Since 1962, a fire burns beneath this town. 1,100 people lived here. Today, five remain."

**Entry points:**
1. **Centralia, PA** — Il fire che brucia dal 1962, mine fire perpetuo
2. **Plymouth, PA** — Altra città con mine fire, 1962
3. **Johnstown, PA** — Flooding del 1889 (non mine fire ma related)
4. **Hazel, KY** — Sinking towns per sinkholes
5. **Sydenham, Canada** — Un altra ghost town

**Perché funziona:** Silent Hill è pop culture reference, facile engagement

**Fonti:**
- https://en.wikipedia.org/wiki/Centralia,_Pennsylvania
- r/AbandonedPorn: "Centralia PA" search

**Perché funziona:** Conspiracy/government angle, alta curiosità

## Video 4: The Most Densely Populated Places Now Empty

**Pillar:** Ghost Towns  
**Idea:** posti che erano among the most densely populated on Earth, ora deserti  
**Hook:**
> "In 1963, this 16-acre island held more people per square meter than anywhere else on Earth. Today, nothing lives there."

**Entry points:**
1. **Hashima Island, Japan** — Battleship Island, 83,000 people/km² → abandoned 1974

3. **Dharavi, Mumbai** — Actually still alive, NOT ghost — skip
4. **Five Pointed Star** — Prison Islands (Devil's Island, etc.)
5. **Density comparison** — Manhattan vs these places

**Perché funziona:** Numbers porn + contrasto dramático

## Video 5: The USSR's Secret Cities

**Pillar:** Secret/Invisible Cities  
**Idea:** Cities that were erased from Soviet maps

1. **Pripyat, Ukraine** — Soviet city, evacuated 1986 post-Chernobyl
2. **Totsk, Russia** — Nuclear test site, town built for it
3. **Bffin** — Closed cities in Russia (ZATO status)
4. **Sevastopol** — Naval bases, access restricted
5. **Chernobyl exclusion zone cities** — Many others besides Pripyat

**Perché funziona:** Cold War mystery + ongoing relevance (Ukraine war)

## Hook Templates per Secret Cities

### COLD_OPEN_ABANDONMENT:
```
"[Place]. In [year], [number] people lived here. In [year], they left. Today, [what you find there]."
```

### COLD_OPEN_FORBIDDEN:
```
"[Place]. You cannot go here. [Number] people used to live here. [Authority] has forbidden entry because [reason]."
```

### COLD_OPEN_IMPOSSIBLE:
```
"[Place]. Scientists found it. But no one built it. No one knows who made it. It has been here for [time]."
```

### ENTITY_MYSTERY_PLACE:
```
"[Place]. [Year it was discovered/abandoned]. [What makes it strange]. [Why no one knows the full story]."
```

## Script Structure (same as Finest Explainer)

```
[0:00-0:03] HOOK — Name + dramatic detail
[0:03-0:15] SETUP — When it was built/founded, by whom, what for
[0:15-1:15] NARRATIVE — What happened, how it declined, the story
[1:15-1:30] IMPACT — Numbers, scope, what's left today
[1:30-1:45] CURRENT STATUS — Can you visit? What's there now?
[1:45-1:50] TRANSITION → next place
```

### Per Secret Cities, aggiungere:
- **"What you can see today"** — Visual details di ruins
- **"Things left behind"** — Objects that give unease
- **"Why it's still abandoned"** — Current status
